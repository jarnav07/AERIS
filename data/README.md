# Data

The repository has one canonical training dataset: the stochastic
Kulfan/XFOIL dataset in `raw/xfoil_training.csv`.

## Canonical training data

`raw/xfoil_training.csv` is generated by:

```bash
uv run airfoil-ml generate-data \
  --cases 10000 \
  --seed 42 \
  --training-output data/raw/xfoil_training.csv \
  --coordinates-output data/raw/generated_airfoils
```

Each generated geometry is a random weighted mixture of three source airfoils
in 18-dimensional Kulfan parameter space. The generator then applies a
lognormal scale factor and a covariance-based perturbation before running XFOIL
at a sampled Reynolds number and a jittered alpha pattern.

The dataset contains the geometry parameters and the XFOIL outputs `Cl`, `Cd`,
and `Cm`. All candidate ML models use this exact same dataset.

Generated companion files are:

```text
raw/xfoil_training.csv
raw/xfoil_training.provenance.json
raw/xfoil_training.failures.jsonl
raw/generated_airfoils/*.dat
```

The provenance file records the random seed and generator/XFOIL configuration.
The failure log records cases where no usable XFOIL solution was produced.
Failed cases are never filled with invented labels.

## CFD reference data

CFD is an independent evaluation reference, not a second training dataset.
Keep the CFD CSV outside the canonical training path and pass it to the
`evaluate` command with `--cfd-csv`.

The CFD reference must use the same geometry and operating-point convention as
the trained model:

```text
18 Kulfan parameters
alpha_deg
reynolds
mach
cl
cd
cm
```

The evaluation code validates the schema and never appends CFD rows to the
XFOIL dataset.

## Data policy

Downloaded/generated datasets, model artefacts, and result plots are not
committed to Git. This keeps the source repository small while preserving
reproducibility through the generator configuration and provenance files.

Do not reintroduce separate fixed-Re, parametric, or hybrid datasets into the
main training pipeline. New datasets should instead be treated as independent
benchmarks or deliberate future experiments with their own documented purpose.
