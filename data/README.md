# Data

This project uses two intentionally separate aerodynamic data sources.

## Local multi-condition XFOIL data

`raw/coordinates/` is populated by `airfoil-ml acquire` from the [UIUC
Airfoil Coordinates Database](https://m-selig.ae.illinois.edu/ads/coord_database.html).
The downloaded files are coordinate text files and should be kept with their
source metadata.

`raw/polars.csv` is generated by running the open-source XFOIL viscous panel
and boundary-layer solver against those coordinates. It contains solver output,
not hand-authored or synthetic aerodynamic labels. The acquisition command
writes a matching `polars.provenance.json` file, including failed solver cases.

## Large fixed-Re dataset

`raw/external/kanakaero/compiled_airfoil_data.csv` is downloaded by
`airfoil-ml download-large` from the [Kanakaero public repository](https://github.com/kanakaero/Dataset-of-Aerodynamic-and-Geometric-Coefficients-of-Airfoils),
using a pinned commit in `src/airfoil_ml/large_dataset.py`.

The source contains 33,705 rows from 2,946 airfoil identities. Each row has
angle of attack, eight CST geometry coefficients, `Cl`, and `Cd`. The source
README documents the aerodynamic data at `Re=100,000`. It does not provide
`Cm` or a Reynolds sweep, so it is used only by the `train-large` fixed-Re
experiment and must not be concatenated with the multi-Re/Cm XFOIL table.
The repository includes an MIT license and cites DOI 10.3390/data9050064;
retain both citations when redistributing derived results.

## Large parametric camber dataset and the hybrid table

`raw/generated_large_coordinates/` and `raw/generated_large/` are produced by
`airfoil-ml generate-camber` from the NACA four-digit camber/thickness
family: 336 designs (camber 0-8%, position 20-70%, thickness 6-18%) swept at
`α = -4° … 14°` across six Reynolds numbers, yielding 31,311 rows from 1,838
successful XFOIL cases. The 166 failed cases (thin/high-camber designs) are
recorded in `_failed_cases.jsonl` and are never replaced with synthetic
values. The generator manifest in `generated_large_coordinates/` names every
airfoil from its design parameters, so the table is fully reproducible.

`raw/hybrid_large/combined.csv` concatenates the 100-airfoil real dataset
(`multi_re_100`) with the 336-airfoil parametric dataset: 37,605 rows across
435 airfoils with no identity overlap. `raw/hybrid_coordinates/` holds the
combined coordinate set. The hybrid table is the training input for the
large-dataset experiment documented in the root README.

The repository intentionally does not commit downloaded datasets, models, or
plots. This keeps provenance explicit and keeps Git history small. The data can
be regenerated with the commands in the root README.
